# 1\. Introdução

## 1.1. Objetivo do Documento

Este documento consolida, revisa e formaliza os requisitos de sistema do software BS Fitness, reunindo e harmonizando os levantamentos realizados por diferentes membros da equipe. O resultado é um documento único, padronizado e completo, destinado à entrega ao cliente.

## 1.2. Descrição Geral do Sistema

O BS Fitness é uma solução digital para acompanhamento personalizado do condicionamento físico e dos métodos de treinamento dos usuários. A plataforma oferece relatórios, planilhas, cronogramas, feedbacks e diagnósticos produzidos tanto por Inteligência Artificial quanto por profissionais certificados.

O sistema é composto por dois módulos distintos:

- Módulo Mobile - voltado ao usuário final (aluno), disponível para Android (versão 8 ou superior) e iOS (versão 13 ou superior).
- Módulo Web Responsivo (ADM/Personal) - voltado ao administrador do sistema e aos profissionais certificados (personal trainers), acessível por navegador.

# 5\. Glossário

| **Termo**                  | **Definição**                                                                                                                                                               |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ADM**                    | Administrador do sistema. Possui acesso total ao módulo web responsivo.                                                                                                     |
| **Anamnese**               | Formulário de avaliação inicial do aluno contendo histórico de saúde, objetivos e limitações físicas.                                                                       |
| **BSB (Bs Básic)**         | Plano de entrada do sistema, com acesso limitado às funcionalidades essenciais.                                                                                             |
| **BSP (Bs Premium)**       | Plano intermediário com acesso expandido, incluindo upload de mídia e análise profissional.                                                                                 |
| **BSPP (Bs Premium Plus)** | Plano completo com acompanhamento personalizado por profissional certificado.                                                                                               |
| **CAPTCHA**                | Mecanismo de verificação para distinguir humanos de bots durante o cadastro e login.                                                                                        |
| **CDN**                    | Content Delivery Network. Rede de distribuição de conteúdo para entrega eficiente de vídeos.                                                                                |
| **CRUD**                   | Create, Read, Update, Delete. Conjunto de operações básicas de gerenciamento de dados.                                                                                      |
| **Diagnóstico**            | Relatório gerado pela IA ou pelo profissional com indicação de melhorias no condicionamento físico.                                                                         |
| **Feedback**               | Retorno sobre o shape/condicionamento do usuário, gerado por IA ou por profissional certificado.                                                                            |
| **IA**                     | Inteligência Artificial utilizada para análise automática de fotos e vídeos do usuário.                                                                                     |
| **LGPD**                   | Lei Geral de Proteção de Dados (Lei nº 13.709/2018). Regula o tratamento de dados pessoais no Brasil.                                                                       |
| **Mapa da Dor**            | Diagrama interativo do corpo humano no qual o usuário registra regiões de dor ou desconforto, com intensidade e tipo, para adaptação dos treinos e orientação profissional. |
| **Personal Trainer (PT)**  | Profissional certificado cadastrado na plataforma para criação de fichas, análise de vídeos e acompanhamento de alunos.                                                     |
| **Shape**                  | Termo utilizado na área fitness para descrever o condicionamento físico e composição corporal do indivíduo.                                                                 |
| **SLA**                    | Service Level Agreement. Acordo de nível de serviço que define a disponibilidade mínima do sistema (99%).                                                                   |
| **TLS/HTTPS**              | Protocolos de comunicação segura que criptografam o tráfego entre cliente e servidor.                                                                                       |
